# Meta Marketing API v26 Actions

Thirteen Actions for the existing `meta-marketing-api` Nango provider (which aliases `facebook`); the two Page-listing operations already exist under `facebook` and are not duplicated. Endpoints are pinned to Graph API `/v26.0/` and all IDs are constrained to numeric strings. Reads request only selected fields and return validated collections plus cursors, not Meta's `paging.next` URL (which can contain access tokens). Reads retry three times; writes explicitly use zero retries.

| Operations | Effect |
| --- | --- |
| `list-ad-accounts`, `list-businesses`, `list-campaigns`, `get-insights` | Read accessible resources only; paginated with `after` and bounded `limit`. |
| `create-campaign`, `create-ad-set`, `create-ad`, `create-ad-creative` | Create resources. Campaigns, ad sets, and ads are explicitly `PAUSED`; creatives are not serving ads by themselves. A creative can create an unpublished Page story and requires a pre-uploaded image hash. |
| `set-campaign-status`, `set-ad-set-status`, `set-ad-status` | `ACTIVE` can start or resume ad delivery and spend; `PAUSED` stops delivery at that level. Effective delivery also depends on other levels and Meta review. |
| `update-campaign-budget`, `update-ad-set-budget` | Change Meta budgets, **not guaranteed hard daily spend caps**. `daily_budget` is an average daily amount: Meta says it may spend up to 25% more on a given day. `lifetime_budget` applies over the configured run, subject to changes in delivery settings. Values are integer minor currency units, not dollars; account-specific rules apply. Increasing a budget on an active hierarchy can increase spending immediately. See [Meta's budget rules](https://developers.secure.facebook.com/documentation/ads-commerce/marketing-api/bidding/overview/budgets). |

The caller must obtain **separate, external authorization** for each write, especially activation and budget changes; OAuth connection or granted `ads_management` scope is not approval for a particular mutation. The templates cannot enforce a caller's approval process or spend limits outside their bounded input ranges. Check ad-account currency, account-specific minimum budget, campaign/ad-set budget ownership, objective/billing/optimization compatibility, special-ad-category compliance, targeting restrictions, scheduling and creative policy before invocation. Creating an ad set with a lifetime budget requires an `end_time`; updating a lifetime ad-set budget also requires `end_time`. Meta may reject otherwise well-formed requests for account-specific policy or compatibility reasons.

Writes are not retried because an ambiguous network failure can mean the mutation succeeded. Do not blindly replay on failure: inspect Meta state first. Mutation responses require a positive Meta acknowledgement and create responses require an ID. No live account was used for these offline contract tests.

Source contract: [Meta Graph Marketing API reference](https://developers.facebook.com/docs/marketing-api/reference/) (notably [campaigns](https://developers.facebook.com/docs/marketing-api/reference/ad-campaign-group/), [ad sets](https://developers.facebook.com/docs/marketing-api/reference/ad-account/adsets/), [creatives](https://developers.facebook.com/docs/marketing-api/reference/ad-account/adcreatives/), [link data](https://developers.facebook.com/docs/marketing-api/reference/ad-creative-link-data/)).
